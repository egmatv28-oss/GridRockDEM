


# GridRockDEM
Prototype Grid (Blocks) DEM Runtime solver for rock mechanics powered by Taichi with comfortable gui. Use Druger-Prager rock model. Created with this agents (Deepseek v4.1 flash and Mimo-v2.6-pro) in Opencode.



https://github.com/user-attachments/assets/b579f000-4dea-4536-879b-717ef85417fe




#How to install
1) Install Python 3.12 from python.org
2) Open cmd and put "pip install taichi"
3) Unpack all files everywhere and start "GridRockDem(number of size model) choice how many block model u want.
4) Use and enjoy. Can change model runtime (add crack, elements, delete elements)
